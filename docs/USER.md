# Manual de Usuario - Sistema de Gestión de Egresados IES

Guía completa para egresados del Instituto de Educación Superior sobre cómo utilizar el sistema de gestión.

## 👋 Bienvenido

El Sistema de Gestión de Egresados IES es una plataforma diseñada específicamente para mantenerte conectado con tu institución y con otros egresados. Aquí podrás:

- **Mantener tu perfil profesional actualizado**
- **Conectar con otros egresados de tu carrera**
- **Recibir oportunidades laborales**
- **Participar en la comunidad de egresados**
- **Acceder a recursos y herramientas exclusivas**

## 🚀 Primeros Pasos

### 1. Registro en el Sistema

#### Requisitos Previos
- Ser egresado del Instituto de Educación Superior
- Tener tu DNI registrado en la base de datos institucional
- Contar con una dirección de email válida

#### Proceso de Registro

1. **Acceder al sistema:**
   - Ir a la página principal del sistema
   - Hacer clic en "Registrarse"

2. **Completar datos básicos:**
   ```
   - DNI (sin puntos ni espacios)
   - Nombre completo
   - Email personal
   - Contraseña segura
   - Carrera cursada
   - Año de egreso
   ```

3. **Validación:**
   - El sistema verificará que tu DNI esté en la lista de egresados
   - Recibirás un email de confirmación
   - Tu cuenta quedará activada automáticamente

4. **Primer acceso:**
   - Usar las credenciales creadas durante el registro
   - Completar tu perfil (recomendado)

### 2. Primer Inicio de Sesión

#### Acceder al Sistema

1. **Ir a la página de login**
2. **Seleccionar "Egresado" como tipo de usuario**
3. **Ingresar email y contraseña**
4. **Hacer clic en "Iniciar Sesión"**

#### Configuración Inicial

Tras tu primer acceso, te recomendamos:

```
□ Completar tu perfil profesional
□ Subir tu CV actualizado
□ Verificar tu información de contacto
□ Explorar las funcionalidades disponibles
□ Configurar tus preferencias de notificaciones
```

## 👤 Gestión de Perfil

### Panel de Perfil

Tu perfil es tu carta de presentación en la plataforma. Incluye:

#### Información Personal
```
- Nombre completo
- Email de contacto
- Teléfono
- Fecha de nacimiento
- Dirección actual
- Foto de perfil (opcional)
```

#### Información Académica
```
- Carrera cursada
- Año de egreso
- Promedio académico (opcional)
- Proyectos destacados
- Reconocimientos recibidos
```

#### Estado de Completitud

El sistema muestra el porcentaje de completitud de tu perfil:

```
🔴 0-30%  - Perfil Básico
🟡 31-70% - Perfil Intermedio
🟢 71-100% - Perfil Completo
```

**Beneficios de un perfil completo:**
- Mayor visibilidad para oportunidades laborales
- Mejores recomendaciones de contactos
- Acceso a funcionalidades premium
- Apareces en búsquedas de otros egresados

### Completar Perfil Profesional

#### Experiencia Laboral

Para cada trabajo que hayas tenido:

1. **Agregar experiencia:**
   - Hacer clic en "Agregar Experiencia"
   - Completar formulario:
     ```
     - Puesto/Cargo
     - Empresa/Organización
     - Fecha de inicio
     - Fecha de fin (o "Trabajo actual")
     - Descripción de responsabilidades
     - Logros destacados
     ```

2. **Ordenar experiencias:**
   - Las experiencias se ordenan automáticamente por fecha
   - La más reciente aparece primero
   - Puedes marcar tu trabajo actual

3. **Editar o eliminar:**
   - Usar los íconos de edición/eliminación
   - Los cambios se guardan automáticamente

#### Formación Académica

Incluye toda tu formación posterior al egreso:

```
Tipos de formación:
- Tecnicaturas adicionales
- Carreras universitarias
- Postgrados y especializaciones
- Maestrías y doctorados
- Intercambios académicos
```

**Para cada formación:**
- Título obtenido o en curso
- Institución
- Año de finalización (o "En curso")
- Estado (Finalizado/En curso/Abandonado)

#### Cursos y Certificaciones

Registra tu formación continua:

```
Información requerida:
- Nombre del curso/certificación
- Institución o plataforma
- Duración en horas
- Fecha de finalización
- Certificado obtenido (Sí/No)
- URL del certificado (opcional)
```

**Categorías sugeridas:**
- Capacitaciones técnicas
- Cursos de idiomas
- Certificaciones profesionales
- Habilidades blandas
- Workshops y seminarios

### Subir CV

#### Formatos Permitidos

```
Tipos de archivo aceptados:
✅ PDF (recomendado)
✅ Microsoft Word (.doc, .docx)

Límites:
- Tamaño máximo: 10 MB
- Se sobrescribe el CV anterior
```

#### Proceso de Subida

1. **Acceder a la sección CV:**
   - Ir a "Mi Perfil" → "Curriculum Vitae"

2. **Subir archivo:**
   - Hacer clic en "Subir CV" o arrastrar archivo
   - Seleccionar archivo desde tu computadora
   - Esperar confirmación de carga exitosa

3. **Verificar:**
   - El sistema muestra preview del CV
   - Verificar que se cargó correctamente
   - Descargar para confirmar que se ve bien

#### Recomendaciones para el CV

```
✅ Buenas prácticas:
- Usar formato PDF para mejor compatibilidad
- Mantener diseño limpio y profesional
- Incluir información de contacto actualizada
- Destacar experiencia relacionada con tu carrera
- Mantener extensión de 1-2 páginas
- Revisar ortografía y gramática

❌ Evitar:
- Archivos muy pesados (>5MB)
- Información personal innecesaria
- Diseños muy elaborados que dificulten la lectura
- Múltiples archivos comprimidos
```

Saludos,

## 🆘 Ayuda y Soporte

### Problemas Comunes

#### No Puedo Iniciar Sesión

```
Verificar:
1. Email escrito correctamente
2. Contraseña sin espacios extra
3. Cuenta activada (revisar email)
4. No bloqueado por intentos fallidos

Soluciones:
- Usar "Recuperar contraseña"
- Contactar soporte si persiste
```

#### No Puedo Subir Mi CV

```
Posibles causas:
- Archivo muy grande (>10MB)
- Formato no permitido
- Problemas de conexión
- Navegador desactualizado

Soluciones:
- Comprimir archivo PDF
- Convertir a formato permitido
- Verificar conexión a internet
- Probar desde otro navegador
```

#### Mi Perfil No Se Guarda

```
Verificaciones:
- Completar campos obligatorios
- Verificar conexión a internet
- Revisar formato de datos
- Probar desde navegador actualizado

Si persiste: Contactar soporte técnico
```
